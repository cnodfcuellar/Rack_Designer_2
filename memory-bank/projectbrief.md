# Project Brief: RACK Designer Next

## Core Purpose
RACK Designer Next is a visual, browser-based tool for designing, documenting, and managing Datacenter infrastructures. It allows users to manage physical locations (Rooms), server racks (Racks), networking/power devices (Devices), and physical cable connections between ports.

## Ultimate Goals
1. Provide a fast, client-side only (PWA) visual editor for datacenter topologies.
2. Enable easy generation and tracking of physical interconnections (port to port).
3. Deliver a premium, responsive, and highly visual UI without relying on heavy frameworks like React or build tools like Webpack.

## Scope
- **In Scope:** Visual topology mapping, rack faceplate rendering, connection management, import/export (JSON/Excel), role-based access control (RBAC).
- **Out of Scope:** Live network monitoring, SNMP polling, automated discovery (this is purely a design/documentation tool).
