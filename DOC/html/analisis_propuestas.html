Ruta A — Refactorización Arquitectural

// Mejoras estructurales para escalabilidad a largo plazo

🏗️
Ruta A · Arquitectura

Refactorización para Escalabilidad

RACK Designer tiene un codebase sólido, pero con el tiempo el módulo modals.js (~922 líneas) y topology.js (~826 líneas) se vuelven difíciles de mantener. Esta ruta propone dividirlos en módulos cohesivos, implementar un sistema de plugins para el catálogo, y migrar el motor de topología a un Worker thread para liberar el hilo principal.

A2 · Motor de Topología en Web Worker

El drawTopo() corre en el hilo principal a 60fps. En setups con 200+ nodos causa jank perceptible durante drag&drop simultáneo. Migrar el cálculo de posiciones a un OffscreenCanvas + Worker libera el hilo de renderizado UI.

// topology-worker.js (Web Worker)
self.onmessage = ({ data }) => {
  const { nodes, edges } = data;
  // Force-directed layout calc
  const positions = computeLayout(nodes, edges);
  self.postMessage({ positions });
};

// main thread
const worker = new Worker('topology-worker.js');
worker.postMessage({ nodes, edges });

Ruta C — Seguridad y Cumplimiento

// Hardening completo para entornos empresariales y auditorías de seguridad

🔒
Ruta C · Seguridad

Hardening para Entornos Empresariales

Las credenciales de equipos de red (contraseñas de switches, routers, firewalls) son altamente sensibles. Esta ruta propone un modelo de seguridad por capas: cifrado en reposo con Web Crypto API, control de acceso por PIN de sesión, y exportaciones auditables con firma de integridad.

C1 · Cifrado de Credenciales con Web Crypto API

Implementar AES-GCM 256-bit para cifrar los campos pass antes de guardarlos en localStorage. La clave se deriva del PIN del usuario con PBKDF2. Sin el PIN, los datos son ilegibles incluso accediendo directamente al localStorage del navegador.

🔐
AES-GCM 256-bit en reposo
Cifrado nativo via window.crypto.subtle
Esfuerzo: Medio · Impacto: Crítico
🗝️
PBKDF2 para derivación de clave
PIN del usuario → CryptoKey de 256 bits
Esfuerzo: Medio · Impacto: Crítico
crypto-store.js (propuesto)
async function encryptPass(pass, pin) {
  const key = await deriveKey(pin);
  const iv = crypto.getRandomValues(
    new Uint8Array(12));
  const buf = await crypto.subtle.encrypt(
    { name: 'AES-GCM', iv },
    key, new TextEncoder().encode(pass)
  );
  return btoa(String.fromCharCode(...new Uint8Array(buf)));
}
